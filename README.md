#Purpose of Repository
This repository demonstrates simple print function and make changes to the line of code to add a print function for the collaborator's name and for them to review the changes.

##Steps taken:
1. Run git bash on desktop and create folder ite_tutorial by typing command mkdir ite_tutorial to store txt file
2. Open that folder by typing cd ite_tutorial
3. Initialize your repository by typing git init
4. Once initialized open the folder and create your text file with the print function and save
5. Add the file to your staging area by typing 'git add <name of text.txt>'
6. Commit your txt file by typing git commit -m "Insert your message here"
7. Create a new branch by typing git branch <name of branch>
8. Push your repository & newly created branch to github by executing the following commands:
   -'git remote add origin' 
   -'git branch -M main'
   -'git push -u origin main'
   -'git push -u origin <name of branch>'
9. On github, open your branch and within the text file add the additional print function and commit those to that branch.
10. Thereafter click on compare & pull, check code lines, assign your reviewer on the top right and click on create pull request.
11. Review completed by the reviewer. Once the review is finished they will submit their approvial via the files change tab.
12. After receiving review approval, verify there is no merge conflict and then merge the pull request to commit all changes to main branch.
